# docs/literature/

문헌 조사 결과 (scholar 담당).

- `<YYYY-MM-DD>-<주제>.md` — 조사 보고서 (질문, 문헌 표, 근거 위치, 제안)
- `references.bib` — 검증된 참고문헌. writer는 여기 있는 것만 인용한다
- `pdfs/` — **내가 직접 구한 논문 PDF를 넣는 곳.** 파일명 예: `Cerezo2021_barren_plateaus.pdf`
  - scholar가 웹 검색보다 먼저 읽는다 (`pdftotext`로 텍스트 추출, 근거는 페이지 번호로)
  - git에 올리지 않는다 (`.gitignore`). 저작권·용량 때문
